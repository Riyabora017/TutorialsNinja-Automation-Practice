## TutorialsNinja Automation Practice

Selenium automation practice project built using Java, Selenium WebDriver, TestNG, and Maven.

## Project Focus

Automated user registration and validation scenarios for the TutorialsNinja demo e-commerce application.

## Tech Stack
- **Java**
- **Selenium WebDriver**
- **TestNG**
- **Maven**
## Covered Scenarios
- **User registration with mandatory & all fields**
- **Validation of warning messages**
- **Newsletter subscription verification**
- **Navigation flow validation**
  
## How to Run

Clone the repository and execute test classes using TestNG.
